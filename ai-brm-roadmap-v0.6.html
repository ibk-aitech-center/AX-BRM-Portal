02

행외 개발 · 생성형 AI 툴 구간

폐쇄망 안에서는 생성형 AI 코딩 도구를 쓸 수 없으므로 개발은 행외에서 합니다.

개발용 데이터 세 갈래

업무 특성에 따라 세 갈래로 갈리고, 갈래마다 행외로 나가는 것이 다릅니다. Case B가 표준이고 Case C는 심의를 거친 예외입니다.

케이스업무 특성행외로 나가는 것개발 · 반입 방식추가 소요
Case A
가상 데이터		 사용자 입력값만으로 결과가 나옴시뮬레이터, 계산기, 문서 생성기, 규정 안내 없음 개발자가 임의로 지어낸 값으로 개발. 구조 제약도 없습니다반입 후 — 데이터 연계 작업 없음. 반입 판정(03)에서 "행내 데이터 불필요" 경로 없음
Case B
합성 데이터
· 표준		 업무 흐름·화면·집계는 재현해야 하나 값 자체는 실제일 필요 없음랩 과제 대부분이 여기 데이터 구조만테이블·컬럼명, 타입·길이, 코드값 목록, 컬럼 설명. 값은 0건 반출한 구조로 생성한 합성 데이터. 건수와 코드 분포는 통계 요약치로만 맞춥니다반입 후 — 데이터 접근 어댑터만 실제 커넥터로 교체하고 연결 검증 없음구조 반출은 경량 확인
Case C
비식별 실데이터		 실제 값의 분포·이상치·표기 흔들림이 있어야 로직이 성립원문 추출 정확도 검증 등 비식별 처리된 실데이터 일부반출 적정성 검토 승인이 선행 가명·마스킹 처리본으로 개발. 반출 범위·기간·파기 시점을 사전 확약반입 후 — Case B와 동일. 다만 반출본 파기 확인이 추가 +3~5주승인 여부 자체가 불확실

데이터 계약 · 행외와 행내가 같은 모양이어야 하는 이유

03

행내 반입 판정 흐름

반입 신청 시점부터 연계 방식 확정까지의 판정 흐름입니다. 착수 판정 시점에 가판정한 목적지를 여기서 확정합니다. 각 분기의 상세 기준은 배포지 결정(05)과 데이터 연계 방식 결정(07)에 있습니다.

04

배포지와 데이터 연계는 서로 종속되지 않습니다. 따로 물어 따로 결정합니다.

05

배포지 결정

비-AI-HUB 사유는 아래 네 가지만 인정하고, 그 밖의 이유는 재설계로 되돌립니다. 비-AI-HUB 배포 방식 자체는 아직 미정이므로, 해당 판정이 나오면 사유를 기록하고 보류합니다.

06

환경 정합화 체크리스트

행외 개발(02) 결과물을 행내에 반입할 때 깨지는 지점 12개. AI-HUB 표준 이미지를 쓰지 않는 경우 전부 개별 확인 대상입니다. 오른쪽 표시는 사후 발견 시의 비용입니다.

반입 전 확인반입 전 정합화 12항목(예시)
  • 01
    런타임 버전재작업

    행내 표준 런타임 버전 목록을 개발 시작 전에 받아 그 버전으로 만듭니다.

  • 02
    외부 패키지 의존성재작업

    폐쇄망에서는 설치 명령이 동작하지 않습니다. 사내 저장소 미러 보유 목록을 사전 제공하고, 없는 패키지는 오프라인 번들로 함께 반입합니다.

  • 03
    CDN 참조재작업

    웹폰트·JS·CSS의 외부 CDN 링크를 전부 로컬 번들로 교체합니다.

  • 04
    외부 API 호출재작업

    외부 LLM API를 포함한 모든 아웃바운드 호출을 제거하거나 사내 대체 엔드포인트로 바꿉니다. 행내 가용 모델·엔드포인트 목록을 상담 때 함께 안내합니다.

  • 05
    OS · 아키텍처 차이경미

    운영 환경이 Linux인 경우 경로 구분자, 파일명 대소문자 구분, 한글 파일명을 점검합니다.

  • 06
    문자셋재작업

    원천이 EUC-KR·CP949인 경우 UTF-8 변환 지점을 명시적으로 설계합니다. 데이터혁신부 협의 때 함께 확인합니다.

  • 07
    DB 커넥터와 SQL 방언재작업

    개발용 경량 DB로 만든 쿼리는 행내 DBMS에서 그대로 돌지 않습니다. 드라이버와 방언을 초기에 확정하고 데이터 접근 계층을 분리합니다.

  • 08
    인증 연동재작업

    자체 로그인 화면은 원칙적으로 불가. 사내 통합인증 연동을 전제로 설계합니다.

  • 09
    네트워크 · 포트 · 인증서협의

    아웃바운드 차단, 포트 개방 신청, 프록시 설정, 사내 CA 인증서 적용. 신청 리드타임을 일정에 반영합니다.

  • 10
    시간대 · 영업일 기준경미

    서버 타임존과 영업일·마감시각 기준을 확정합니다. 배치는 원천 마감 이후로 잡습니다.

  • 11
    오픈소스 라이선스차단 가능

    반입 전에 사용 라이브러리의 라이선스를 확인합니다. 카피레프트 계열은 반입이 막힐 수 있습니다.

  • 12
    반입 절차협의

    소스 반입 신청, 악성코드 검사, 시큐어코딩 점검. AI-HUB 경로에도 동일하게 적용됩니다.

07

데이터 연계 방식 결정

데이터혁신부에 넘기기 전에 온라인인지 배치인지, 배치면 양이 얼마인지까지 정하고 들어갑니다. 컬럼 목록과 컬럼별 사용 목적은 협의 전에 확정합니다.
